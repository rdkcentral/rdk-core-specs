JSON-RPC 2.0 Compliance

The URL used by the Firebolt Client Library to connect to the Firebolt API Gateway includes the RPCv2=true query parameter, confirming that the Client Library uses and accepts only compliant JSON-RPC as specified in this document.

All names used for matching, including method and parameter names, are case sensitive as stated in Section 2 of the JSON-RPC 2.0 Specification.
